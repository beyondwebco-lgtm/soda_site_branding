# Fonts Directory

This directory can hold offline webfont files (`.woff2`, `.woff`, `.ttf`) if self-hosting.
By default, FIZZUP loads high-performance typography directly via Google Fonts:
- **Fredoka** (Weight: 600, 700, 800, 900) - For bold, punchy, retro-modern rounded headers
- **Plus Jakarta Sans** (Weight: 400, 500, 600, 700) - For crisp, modern, readable body text
